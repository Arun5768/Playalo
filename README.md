# Playalo

Playalo is an archived learning sandbox used to practice repository workflows, issues, pull requests, and small documentation changes.

## Project status

**Archived experiment.** This is not a production application and there is currently no runnable build.

## What was explored

- Creating and reviewing issues
- Working with short-lived branches
- Opening and merging pull requests
- Improving repository documentation

The repository is kept as a transparent record of early GitHub workflow practice.
